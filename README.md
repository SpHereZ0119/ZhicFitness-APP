# ZHIC · 个人工作台

只在你的电脑运行的个人学习与生活工作台。需求依据见 [PRD.md](PRD.md)，开发及测试进度见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)。

## 打开应用

1. 双击本文件夹的 `START.cmd`。
2. 浏览器会打开 **http://127.0.0.1:4317**。如果未自动打开，复制这个地址到电脑浏览器。
3. 使用期间保留启动窗口。关闭启动窗口后，网页会停止服务；下次再次双击启动即可。

已具备 Node.js 的电脑也可以在本文件夹执行 `node server.mjs`。本机附带的启动脚本会优先使用 Codex 已安装的 Node.js，不需要联网安装应用依赖。

## 数据保存在哪里

数据保存在浏览器为 `http://127.0.0.1:4317` 分配的本地数据库中。刷新、关闭浏览器及电脑重启后，使用**同一浏览器、同一配置文件、同一地址**即可继续使用。应用服务只监听本机回环地址，不接收其他电脑访问，也不上传数据。

界面会显示保存状态。若显示失败，请保留页面与输入，检查浏览器存储空间或权限，使用重试入口。使用普通浏览器窗口；隐私窗口关闭后可能清除数据。

不要随意切换成 `localhost`、更改端口、清除浏览器网站数据或更换浏览器配置文件，这些操作会使已有数据库无法被当前页面读取。需要迁移时先导出备份。

## 备份和找回

在“数据与设置”导出完整 JSON 备份，保存到电脑的其他文件夹。备份包括所有模块和使用偏好。

恢复前先选择文件、查看记录数量并确认整体替换。应用会在替换前自动保存一份当前数据，之后可从“恢复前的安全备份”入口预览和找回。每次恢复会更新这份安全备份；长期保留的版本请另存为 JSON 文件。

无效或不支持版本的备份不会覆盖当前数据。安全备份和当前数据库都在同一浏览器中；清除浏览器网站数据会一起删除，因此手动导出的文件仍然必要。

## 计划与记录

今日计划负责安排时间；各模块保存实际工作和生活记录。将工作项、训练安排、餐食或游戏加入计划后，会显示来源的最新名称；完成计划不会替你生成开发日志、训练组、实际饮食或游玩时长。

训练重量统一以公斤保存，饮水统一以毫升保存，显示时按设置换算。营养值完全由本人填写，汇总显示“已记录值合计”，未填写数值不估算。

## 运行测试

双击 `TEST.cmd`，或执行：

```text
node --test --test-concurrency=1 tests/*.test.mjs
```

测试使用 Node 内置测试工具和 Playwright 驱动本机 Edge，并创建独立的浏览器临时数据，避免使用日常浏览器数据。当前电脑的脚本会自动读取已有的 Playwright。其他开发环境需本地安装 `playwright` 并安装 Chromium，或设置 `BROWSER_PATH` 指向浏览器；可设置 `PLAYWRIGHT_MODULE_PATH` 指向已安装的 Playwright 包。

测试结果和截图保存在 `test-results`，临时目录为 `.test-tmp`。

阶段八可单独执行 `node --test --test-concurrency=1 tests/stage8.test.mjs`。它用真实 Edge 走通七个导航模块的典型记录流程、完整备份与恢复，在 1440×1000 和 900×800 的桌面视口检查横向溢出并保存截图到 `test-results`。测试收集页面请求，只允许访问本机测试服务；还会关闭浏览器与本地服务，再用相同端口、相同临时浏览器配置重新启动，逐项比对各模块记录和偏好设置。该重启验证不等同于电脑实际断电重启，电脑重启后的人工步骤见下文。

## 实际电脑重启验收

自动测试会关闭并重开独立浏览器配置验证磁盘持久性，不会擅自重启电脑。完整人工验收如下：

1. 用日常浏览器打开固定地址，新增一条可识别的备忘，等待“已保存”。
2. 导出一份备份，然后正常关闭浏览器与本地服务。
3. 正常重启电脑，再双击 `START.cmd`，使用原浏览器配置打开固定地址。
4. 确认备忘及各模块记录保留；此步骤不包含清除网站数据。

第一版包含七个模块，没有登录、联网数据服务、云同步、咨询工作或手机端。
