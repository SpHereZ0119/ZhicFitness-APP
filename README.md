# ZHIC · 个人工作台

学习、开发、健身、饮食和个人计划共用的离线工作台，包含 8 个模块。各设备独立保存，使用 JSON 完整备份迁移数据，不自动同步。

## 直接使用

- **Windows**：运行发布页里的 `ZHIC-Windows-1.1.1-x64.exe`。这是完整独立便携软件，重启电脑后双击即可，不需要 Codex、Node.js、浏览器或服务窗口。重复点击图标会回到已打开的窗口，避免两个程序争抢本地数据库。
- **Android**：下载发布页里的 `ZHIC-Android-1.1.0.apk`，传到安卓手机安装。当前为个人验收版，支持 Android 7.0 或更新系统。
- **iPhone**：在 Safari 打开 [ZHIC 工作台](https://spherez0119.github.io/ZhicFitness-APP/)，选择“分享 → 添加到主屏幕”。首次联网加载完成后，核心计划和记录功能可离线使用；教学视频仍需要网络。

安装文件见 [GitHub 发布页](https://github.com/SpHereZ0119/ZhicFitness-APP/releases)。多端构建和验收方法见 [MULTIPLATFORM.md](MULTIPLATFORM.md)。

## 保存、备份与迁移

界面显示“已保存”后，记录已经写入当前设备的本地数据库。新 Windows 软件与以前 `127.0.0.1:4317` 网页使用独立的数据空间；先在旧版“数据与设置”导出完整备份，再在新软件选择文件、预览并确认恢复。

完整备份包括 8 个模块、个人偏好和关联关系。恢复会整体替换当前数据，并保留恢复前的本地安全备份；无效文件不会覆盖当前数据。卸载应用或清除网站数据会删除本地记录，请将导出的文件另存到妥善的位置。

今日计划与实际训练、实际饮食、工作日志和游玩记录分别保存。完成计划不会自动生成实际记录。重量以公斤保存，饮水以毫升保存，设置换单位只改变显示，不改变物理量。

## 开发和验证

安装 Node.js 22 或更新版本，然后运行：

```text
npm ci
npm start
npm test
```

开发页面位于 `http://127.0.0.1:4317`，独立软件无需此服务。测试使用真实 Edge、独立临时数据库和 Node 内置测试工具，可通过 `PLAYWRIGHT_MODULE_PATH` 和 `BROWSER_PATH` 指定测试运行环境。

发布流程只从默认 `main` 分支部署 GitHub Pages；开发提交保存在 `master`，测试通过后将相同提交快进到 `main`。产品需求见 [PRD.md](PRD.md)。
